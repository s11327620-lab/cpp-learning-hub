Lab 09：cStrings & Class string

學習目標

  • 了解 C-String 與 class string。
  • 會使用 strlen、strcpy、strcmp。
  • 會使用 find、substr、getline。

C-String 重點

C-String 使用 char 陣列儲存文字，最後以 \0 結束。

char text[20] = "Programming"; cout << strlen(text) << endl;

class string 重點

string str = "I love nycu"; int pos = str.find("nycu");

Exercise：Longest Word

string word; int maxLength = 0; for (int i = 0; i < 10; i++) { cin >> word; if (word.length() > maxLength) { maxLength = word.length(); } }

常見錯誤

  • find 找不到會得到 string::npos。
  • substr 第二個參數是長度。
  • getline 前要注意換行字元。
